# Ecommerce-dataset-analysis-
Making an interactive dashboard to find the total orders , delays, returns, payment modes to analyze the inefficiens to improve the Supply chain network.

KEY FINDINGS :
Revenue: Total ₹8.93 Cr across Jan–Mar 2024, with an average order value of ~₹89K. February was the strongest month.

Delivery performance: Only 22.3% of orders were successfully delivered — the majority ended up Returned (27.8%), Delayed (25%), or Cancelled (24.9%). 

This is a significant operational red flag worth investigating.

Categories: Electronics leads revenue at ~39.7%, followed by Furniture (30.6%) and Fashion (29.6%).

Geography: Pune, Delhi, and Bangalore are the top-performing cities.

Payment: All four modes (COD, Credit Card, Debit Card, UPI) are nearly evenly split, suggesting no dominant preference.

Products: Mobile phones are the top revenue driver, followed by T-shirts, Sofas, and Shoes.
